# Habit.swift 📅

A habit tracking app built in **SwiftUI** — my practice project to get comfortable with SwiftUI state management, lists, and a clean mobile UI.

## ✨ Features
- Create and manage daily habits
- Progress tracking and completion state
- Simple, modern SwiftUI interface

## 🛠️ Built with
`Swift` `SwiftUI` `Xcode`

Part of my journey to ship real iOS apps — feel free to explore the code and suggest improvements.
